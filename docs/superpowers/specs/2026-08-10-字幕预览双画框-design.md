# 字幕预览双画框与样式扩展（M4 工作台）设计

> 日期：2026-08-10
> 状态：已获用户批准（brainstorming 完成）
> 范围：automotion-v7 工作台字幕环节（client + shared 类型）

---

## 1. 背景与目标

现状：字幕环节单个 16:9 画框（背景 = storyboard 第一段 seg-01 镜头第一帧），示例文字固定「示例字幕：时势造英雄」，样式控件有限（字体/字号/字间距/文字色/描边色/描边宽/背景色/位置/对齐）。

目标：

1. **双画框对比**：纵向两个画框，分别展示「四字效果」与「十六字超长字幕」的排版视觉，样式调整实时同步到两个画框
2. **画框缩放**：现有画框缩小为当前宽高的 70%（`maxWidth 1800 → 1260`，16:9 比例不变）
3. **样式属性扩展**：字重、斜体、行间距、背景透明度、背景圆角、背景内边距、阴影（颜色/模糊/透明度/X 偏移/Y 偏移）、整体不透明度、描边开关
4. **颜色控件升级**：色块 + 原生取色盘 + 文本输入 + 纸墨风预设色板，三者同步（用户选定方案 C）
5. **字幕总开关**：`enabled` 决定整片是否渲染字幕（默认开启），M5 合成时消费
6. **安全边距参考线**：画框内虚线参考线辅助排版，仅预览不落盘
7. **滚动查看**：预览区可滚轮滑动，原生滚动条位于预览区右缘（属性面板左侧）

## 2. 范围

### 做

- client：`SubtitlePanel.tsx`（双画框布局、示例文字、新控件、颜色控件、安全边距线、滚动）、`App.tsx`（传 seg-01 镜头，已在字幕环节使用）
- shared：`SubtitleStyle` 类型扩展 + `isSubtitleStyle` 校验同步
- 验证：tsc / validate-m2 / scan-pollution / vite build / 浏览器回归

### 不做

- 时间轴、入场/出场/逐字动画（M5 整片合成阶段）
- 分段独立字幕样式（M4 决策：全片统一）
- 自由拖动字幕定位（需要 x/y 拖拽交互，收益一般，本次不引入）
- 渐变文字、竖排文字（与纸墨风不符）
- 字幕文字编辑（文字来自第一步转录，字幕环节只定样式）

## 3. 布局设计

```
+-----------------------------+--------------------------+
| 预览区（可滚动，overflow-y: auto）| 属性面板（宽 300，可滚动）   |
|                             | 字体下拉 / 颜色控件 /       |
|  [画框一 16:9]               | 数值控件 / 位置对齐 /       |
|  示例文字：四字效果            | 保存 / 返回                |
|                             |                          |
|  [画框二 16:9]               |                          |
|  示例文字：十六字超长字幕       |                          |
|                             |                          |
|  滚动条在此区域右缘            |                          |
|  （属性面板左侧）              |                          |
+-----------------------------+--------------------------+
```

- 整体为左右两列等高并排：左侧预览区（flex: 1，可滚动），右侧属性面板（固定宽 300，可滚动），两者高度均为容器 100%
- 两个画框尺寸完全一致，`maxWidth 1260`（当前 1800 的 70%），`aspectRatio 16 / 9`
- 画框纵向间距 16px
- 背景：两个画框都用 seg-01 镜头第一帧（各自独立 `@remotion/player`，未定稿用匹配 Top1 + 组件默认参数；镜头加载失败显示占位，字幕仍可预览）
- 示例文字为固定占位（不改样式数据）：画框一「四字效果」，画框二「用于展示十六字超长字幕的视觉效果」（16 字）
- 所有样式调整实时同步到两个画框；字号/描边/阴影/行距按各画框宽度等比缩放（基准 1920）
- 安全边距参考线：每个画框内叠加虚线框（左右/上下各留 5%），纯预览辅助，不写入样式数据

## 4. SubtitleStyle 扩展（shared/types.ts）

新增可选字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `enabled` | boolean | 字幕总开关，默认 true；关闭时画框不显示示例文字 |
| `fontWeight` | number | 字重（400 常规 / 700 加粗） |
| `fontStyle` | `'normal' \| 'italic'` | 斜体 |
| `lineHeight` | number | 行距倍数（如 1.35） |
| `opacity` | number | 整体不透明度 0-100 |
| `strokeEnabled` | boolean | 描边开关，默认 true |
| `backgroundOpacity` | number | 背景透明度 0-100 |
| `backgroundRadius` | number | 背景圆角 px |
| `backgroundPadding` | number | 背景内边距 px |
| `shadowColor` | string | 阴影颜色 |
| `shadowBlur` | number | 阴影模糊 px |
| `shadowOpacity` | number | 阴影透明度 0-100 |
| `shadowOffsetX` | number | 阴影 X 偏移 px |
| `shadowOffsetY` | number | 阴影 Y 偏移 px |

`isSubtitleStyle` 校验同步扩展：数值字段校验有限数字，字符串字段校验字符串，枚举字段校验枚举值，布尔字段校验布尔；旧数据（缺新字段）仍通过校验（全部可选）。

## 5. 颜色控件（方案 C）

`ColorField` 组件，应用于文字颜色 / 描边色 / 阴影色 / 背景色：

- 色块：`<input type="color">` 原生取色盘，点击弹出系统取色
- 文本输入：6 位 hex（`#rrggbb`），与取色盘双向同步；非法输入红框提示、保留上次合法值
- 预设色板：纸墨风常用色（来自 `_system/colors.ts` 的 G 色板：bg / ink / accent / border / card / line 等），点击即选
- 透明度由独立滑条控制（背景/阴影/整体各有对应透明度字段），不在 hex 里处理

## 6. 数据流

- 面板本地 `effective = { ...DEFAULT_STYLE, ...style }` 用于回显与预览（未设置字段显示默认值）
- `onChange` 实时更新 `subtitleStyle` state → 两个画框实时重渲染
- 保存 POST `/api/storyboard` 写入 `storyboard.meta.subtitleStyle`（含 `enabled` 与新字段）
- M5 合成时按 `subtitleStyle`（含 `enabled`）决定字幕渲染，本设计不涉及 M5 实现

## 7. 错误处理

- seg-01 镜头加载失败 → 画框显示占位提示，示例字幕仍可预览
- 颜色输入非法 → 红框提示，不覆盖上次合法值
- 数值输入允许临时空值（`effective` 回退默认），保存时按类型写入

## 8. 验证标准

- `npx tsc --noEmit` 0 错误
- `node scripts/validate-m2.mjs` 通过（含更新后的 `isSubtitleStyle` 校验与负面测试）
- `node scripts/scan-pollution.mjs` 0 命中
- client `vite build` 通过
- 浏览器回归：
  - 双画框出现且同尺寸、同背景（seg-01 第一帧）
  - 两框示例文字正确（四字效果 / 十六字长句）
  - 调整字号/字重/斜体/行距/颜色/描边/阴影/背景/不透明度 → 两框实时同步
  - 颜色控件：取色盘选色 / 文本输入 / 预设色板点选，三者同步
  - `enabled` 关闭 → 两框字幕隐藏；保存后 `subtitleStyle.enabled=false` 落盘
  - 预览区滚动可用（滚轮 + 侧边滚动条）
  - 安全边距参考线显示且不落盘

## 9. 已确认决策（勿推翻）

- 两个画框尺寸一致（都 70%）
- 两个画框背景都用 seg-01 镜头第一帧
- 示例文字：画框一「四字效果」，画框二「用于展示十六字超长字幕的视觉效果」
- 颜色控件取方案 C（色块 + 取色盘 + 文本 + 预设色板）
- 字幕总开关 `enabled` 默认开启，语义为整片是否渲染字幕
