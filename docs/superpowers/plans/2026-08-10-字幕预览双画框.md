# 字幕预览双画框与样式扩展 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 工作台字幕环节改为双画框（四字/十六字示例）实时预览，扩展字幕样式属性（字重/斜体/行距/背景组/阴影组/整体不透明度/描边开关/字幕总开关），颜色控件升级为「色块+取色盘+文本+预设色板」。

**Architecture:** client 侧 `SubtitlePanel.tsx` 渲染两个并排等高的 16:9 画框（背景均为 seg-01 镜头第一帧，`@remotion/player` 暂停帧），示例文字为固定占位，样式调整通过同一 `effective` 样式实时同步到两框并按画框宽度等比缩放；`shared/types.ts` 扩展 `SubtitleStyle` 与 `isSubtitleStyle` 校验；颜色控件独立为 `ColorField.tsx` 组件。

**Tech Stack:** React + TypeScript + Vite + @remotion/player（项目已有）。

## Global Constraints

- 工作台不做 AI；字幕环节只定样式，不做文字编辑与时间轴（动画属 M5）
- 验证基线：`npx tsc --noEmit` 0 错误、`node scripts/validate-m2.mjs` 通过、`node scripts/scan-pollution.mjs` 0 命中、client `npx vite build` 通过
- 013B 项目数据（E:\桌面\打破信息差\视频文件\013B）不进仓库
- 示例文字为固定占位（画框一「四字效果」、画框二「用于展示十六字超长字幕的视觉效果」），不写入样式数据
- `SubtitleStyle` 新增字段全部可选，旧数据（缺新字段）必须通过 `isSubtitleStyle` 校验
- 透明度统一 0-100 整数（滑条）；颜色文本输入为 6 位 hex（`#rrggbb`）
- 两个画框尺寸一致（`maxWidth 1260` = 当前 1800 的 70%，16:9 比例不变）
- 安全边距参考线仅预览辅助，不落盘

- [ ] **Step 4: 扩展 `isSubtitleStyle` 校验**

在现有循环后追加（沿用 `isNum`/`isStr`/`isObj` 辅助函数）：

```ts
export function isSubtitleStyle(x: unknown): x is SubtitleStyle {
  if (!isObj(x)) return false;
  const pos = x.position;
  if (pos !== undefined && !['bottom', 'top', 'center'].includes(pos as string)) return false;
  const al = x.align;
  if (al !== undefined && !['left', 'center', 'right'].includes(al as string)) return false;
  const fs = x.fontStyle;
  if (fs !== undefined && !['normal', 'italic'].includes(fs as string)) return false;
  for (const k of [
    'fontSize', 'strokeWidth', 'letterSpacing', 'fontWeight', 'lineHeight',
    'opacity', 'backgroundOpacity', 'backgroundRadius', 'backgroundPadding',
    'shadowBlur', 'shadowOpacity', 'shadowOffsetX', 'shadowOffsetY',
  ] as const) {
    if (x[k] !== undefined && !isNum(x[k])) return false;
  }
  for (const k of ['fontFamily', 'color', 'strokeColor', 'backgroundColor', 'shadowColor'] as const) {
    if (x[k] !== undefined && !isStr(x[k])) return false;
  }
  for (const k of ['enabled', 'strokeEnabled'] as const) {
    if (x[k] !== undefined && typeof x[k] !== 'boolean') return false;
  }
  return true;
}
```

- [ ] **Step 1: 创建 ColorField 组件**

```tsx
// 颜色控件：色块（原生取色盘）+ 文本输入 + 纸墨风预设色板，三者同步
import { useState } from 'react';

const PRESETS = [
  '#2c2416', '#faf7f2', '#b4543c', '#c8b89a', '#e8e0d2',
  '#5b5b5b', '#ffffff', '#000000', '#d8a35a', '#7a9e7e',
];

export const ColorField: React.FC<{
  label: string;
  value: string;
  onChange: (hex: string) => void;
}> = ({ label, value, onChange }) => {
  const [invalid, setInvalid] = useState(false);
  const normalize = (s: string) => (/^#?[0-9a-fA-F]{6}$/.test(s) ? (s.startsWith('#') ? s : '#' + s) : null);
  return (
    <label style={{ display: 'block', marginBottom: 8, fontSize: 12 }}>
      {label}
      <div style={{ display: 'flex', alignItems: 'center', gap: 6 }}>
        <input type="color" value={normalize(value) ?? '#000000'} onChange={(e) => onChange(e.target.value)} style={{ width: 40, height: 26, padding: 0, border: '1px solid #ccc', borderRadius: 4, cursor: 'pointer' }} />
        <input
          type="text"
          value={value}
          onChange={(e) => {
            const n = normalize(e.target.value);
            if (n) { onChange(n); setInvalid(false); } else setInvalid(true);
          }}
          style={{ flex: 1, padding: '4px 8px', boxSizing: 'border-box', border: invalid ? '1px solid #c00' : '1px solid #ccc', borderRadius: 4 }}
          placeholder="#rrggbb"
        />
      </div>
      <div style={{ display: 'flex', gap: 4, marginTop: 4, flexWrap: 'wrap' }}>
        {PRESETS.map((c) => (
          <button key={c} onClick={() => onChange(c)} style={{ width: 18, height: 18, background: c, border: c === value ? '2px solid #4a90d9' : '1px solid #ccc', borderRadius: 3, cursor: 'pointer', padding: 0 }} title={c} />
        ))}
      </div>
    </label>
  );
};
```
