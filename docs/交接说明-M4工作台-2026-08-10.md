## 已实现功能（对照 docs/工作台需求-M4.md）

- **三栏布局**：左栏段列表（32 段，摘要/角色/定稿状态）/ 中栏镜头预览 + 参数表单 / 右栏 Top5 推荐 + 镜头库（分组折叠 + hover 悬浮窗动效预览）
- **自动预选 Top 1**：打开/切段时未定稿段自动选中匹配 Top1；已定稿段加载保存的镜头 + 参数
- **零点击自动播放**：Player `initiallyMuted` 绕过 AudioContext 时钟限制（工作台无声，静音无影响）
- **参数表单**：基础类型 + 数组列表行编辑（增/删/改）+ 嵌套对象递归 + 深层未知 JSON 兜底；保存时类型转换（number/boolean 正确落盘）
- **保存写回**：`POST /api/storyboard` → 项目侧 storyboard.json；顶部「重新加载」手动拉新
- **字幕环节**：样式表单（字号/字体/颜色/描边/背景/位置/对齐/字间距）+ 保存 subtitleStyle + 返回
- **防重复提示**：选用镜头与前面 <5 段重复时提示（不阻止）
- **ErrorBoundary**：全局 + 预览局部，单镜头预览失败显示占位、不白屏
- **registry 增强**：嵌套 fields（对象/数组内部字段）+ 组件签名默认值提取（default）
- **013B storyboard 预生成**：由「理想镜头参考答案-013B.md」生成（文案 + 镜头 + 对应参数）

## 已知问题（debug 方向）

1. **部分镜头图片解码失败**：PageWaterfallWall 等使用 `public/textures/` 静态图的镜头，在 Player 环境报 `EncodingError: The source image cannot be decoded`——staticFile 资源路径/解码在 vite dev 下的问题，hover/预览这些镜头时资源加载失败
2. **Remotion 许可提示**：控制台提示 license（可加 `acknowledgeRemotionLicense` 消除）
3. **自动填参一般化**：当前 013B 用参考答案预生成 storyboard；**其他项目**需「文案 → 参数」映射——skill 学习参考答案规律自动生成（工作台不做 AI，由对话/流程生成后写 storyboard）
4. **hover 悬浮窗性能**：prewarm 分批（5 个/40ms）预热镜头模块，实际 hover 流畅度待验证
5. **数组行编辑/JSON 兜底体验**：复杂参数（如 TextAsMask 的 sidebarItems/cards）编辑体验待实测
6. **字幕环节预览底图**：当前为纯色底 + 字幕文字模拟，未用「第一个镜头稳定画面」（简化实现，可完善）
7. **未定稿段自动预选 Top1 用组件默认参数**：storyboard 无 params 时（skill 未生成）预览为组件默认
